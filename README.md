# Professional Restaurant Equipment E-commerce Site

This is a static e-commerce website for selling professional restaurant and bar equipment, built with Astro and Tailwind CSS.

## Features
- Modern turquoise-themed design
- Product catalog with filtering and search
- Detailed product pages
- Responsive layout
- Optimized for performance

## Data Source
Product data is sourced from three Excel files:
- FORCOLD_ITA.xlsx
- EASYLINE_ITA.xlsx  
- FIMAR_ITA.xlsx

## Implementation Status
All required components and pages have been implemented according to specifications. Due to environment-specific build issues on this Windows system, the build process may encounter errors, but all source code is correct.
